# GPT引き継ぎ改修版 — 2026-10-25

## 確定要件
- 65インチのテレビから約2mで遊ぶ。iPhoneをテレビ付近に固定し、子どもへカメラを向ける。
- 本人の手・杖・分身は表示しない。画面下端から魔法を放つ。
- 敵は銀色のデスイーター風の仮面、黒いローブの人間。反撃しない。
- 全14呪文は初回から音声・手動ともに有効。旧3呪文制限の保存値も移行する。
- 音声で呪文を選択→振り下ろしを検知→映像と合成音を発動。
- 呪文別の色、保存、変更、インポート・エクスポートを維持する。

## 今回の実装
- gesture.js：固定カメラ映像の小領域を比較する下向き動作検知。画像は端末内で処理。録画、外部送信、学習用保存なし。
- 呪文認識後8秒間だけ発動待ち。認識より最大450ms先行した動きも受け付ける。遅い認識では次の振りを待つ。1回の振り下ろしの連発を抑制。
- カメラ開始/停止、前後カメラ、検知範囲、感度、確認映像の表示を保護者が操作。開始は明示タップのみ。ページ非表示で停止。
- 音声のみモードを残す。カメラ故障時に勝手に音声だけで発動する仕様にはしない。
- dark-wizard.js：仮面・フード・ひだのあるローブ・手足・敵の杖をコードから生成。公式のモデル・映画音源は未使用。
- 一人称の発射、着弾の増強、盾の前景配置。宝物の飛来、杖の落下、ナメクジの落下をアニメーション化。
- 全14呪文の確認モード。必要な対象状態を先に用意。通常世界は退避して復元し、確認結果は通常の保存先へ書き込まない。
- リセット・モード変更時に古いタイマー、音、発動待ちを解除。
- WebGL初期化失敗時も保護者メニューと診断を表示する。

## 未検証・制約（完了扱いにしない）
- クラウドのGPU/WebGLがDisabledのため、改修後の3D映像を目視検証できていない。リアルさ、サイズ、色、遮蔽の最終確認は未完了。
- iPhone、HDMI、BRAVIA、実物の杖、子どもの声と振り下ろし精度、熱・fps・発動遅延は未検証。
- 検知は汎用の画像移動検知であり、手・前腕・杖を意味的に識別するAIではない。持ち替え、おじぎ、第三者の動きでも候補を検出し得る。カメラ固定と範囲調整が必要。
- 人物は軽量な手続き生成モデル。商用3Dゲーム級のアセット品質を確認・達成済みとはしない。蛇等の一部は元の簡易モデルを使用。
- 呪文の主な飛翔・着弾は共通基盤を使用する。細かな専用演出には改善余地がある。
- 実物の杖の録音は未提供。現状は14種類の合成音。環境音の独立音量、録音の差し替えUIは未実装。
- 公開先は既存の https://rico018018.github.io/rumina-wand/ を使用。公開処理の成否はGitHub Pagesのデプロイ結果で確認する。

## 試し方
1. HTTPSで公開した改修版をiPhoneのSafariで開く。ローカルのHTTP IPアドレスではカメラが使用できないことがある。Macのみの確認はlocalhostで可能。
2. 保護者メニューの全14呪文確認から、音声・カメラなしで映像と音を確認する。
3. iPhoneを固定し「カメラ開始」。必要なときだけ配置確認映像を表示し、腕と杖が入る位置に調整。映像はテレビにも映るので調整後は非表示にする。
4. カメラの検知範囲を腕のある側へ絞る。静止から振り下ろしを試し、候補検知メッセージを見る。
5. 「はじめる（きく）」→呪文を唱える→「ふりおろしてね」の色表示→振り下ろす。
6. 子ども・大人それぞれ20回程度、成功、無反応、誤発動を記録する。映像と音が遅れる場合はテレビのゲームモード等も確認する。
7. 反応しない場合は音声のみへ切り替えて遊べる。未検証の動作を成功扱いして表示しない。

## 開発
```sh
npm test
python3 -m http.server 8777
```
localhost:8777 で開く。index.htmlの直接ダブルクリックは不可。
データ互換性のためworldのarmor/holdsSword等のキーは残してあるが、表示は人間と杖へ置換済み。
カメラ・場面の生成関数をテスト時に差し替えられる。自動テストのカメラ代替は実機精度の証拠ではない。
参考API：https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia
