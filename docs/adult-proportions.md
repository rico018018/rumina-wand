# 成人のシルエットへの修正

以前は顔面高0.44に対して全高約2.03、フード高約0.59で、頭部が目立つ比率だった。

- 頭部グループを0.58倍にし、顔面高約0.255、フードを含む全高約1.90に変更。顔面高に対する全高の比率は4衣装で7.45〜7.50。これは造形の管理値で、頭頂〜顎で測る厳密な頭身値ではない。
- 肩幅・腰幅・裾幅を縮め、体の輪郭と首の接続を整理。
- 脚は股関節0.96、太もも・すねの2つの形状に変更。足底は床の高さを保持。
- 袖は上腕から手首へ細くし、指は長さを変え、手と杖を新しい手首位置に接続。
- 静止・歩行時の腕の開き角度を0.24から0.08ラジアンへ縮小。
- ローブの均一で強いひだを減らし、肩布・袖口・ベルトを新しい体格に合わせる。

検証：4衣装の形状・頭部比率・接地・衣装変更時の解放、および既存の呪文テストを実施。検証環境はWebGL無効のため実際の描画とテレビ実機は未確認。手続き的3Dモデルであり、実写撮影・人物スキャンと同等の品質は保証していない。
