# 横画面とSafari表示

- 操作は左下にマイク・カメラ・リセット・保護者設定を44px角で配置。ON/OFFを文字で保持。呪文ボタンは右下124×44px。
- 左下の通知は中央下へ移動し、短い通知は1行。idle通知は2.6秒後に隠し、armed/casting/error等は隠さない。
- 100dvhとResizeObserverでSafariの表示領域変更・回転に追従する。
- 背景から浮いて見えた大型棚を床に置いた宝箱へ置換。召喚開始位置も一致させる。
- manifestでstandalone起動を宣言。iPhoneは共有→ホーム画面に追加→Webアプリとして開く→追加したアイコンから起動。SafariのUIそのものはページのCSSでは制御しない。
- Fullscreen APIが利用可能な環境だけ保護者画面に全画面ボタンを表示。失敗時はホーム画面起動の案内を表示。

検証：130件の既存テスト通過。Chromeの横画面で44pxボタンの非重複、設定開閉、リセットと通知を確認。検証ブラウザはWebGL無効のため3Dの描画は未確認。iPhone Safari/ホーム画面起動、HDMI実機は未確認。
