# 大きな魔法演出と子ども向け照合

## 演出

- 通常の粒子枠1600→2200。着弾の基本火花数320→540（軽量時130→180）。固定枠を循環し、無制限には増やさない。
- 着弾余韻1100→1800ms。弾道を太くし、床の波紋・物体への照明を強化。
- 14呪文に衝撃波、渦、盾、上昇する光、全体波の形を割り当てる。3本のリング、64本の光線、縁に光る球面を使う。画面端に滑らかな色の照り返し。白い全画面点滅は使わない。
- 振り下ろし発動は従来どおり即座に発射し300msで着弾。音と世界の状態変更もこの時刻に合わせる。プレイヤーの杖・手は画面に描かない。

## 子どもの発話

- 初期設定を日本語 ja-JP、child判定へ変更。既存利用者にも1回だけ移行する（recognitionVersion:2）。以後選んだ言語・厳しさは保存する。
- 長音・促音・小書き音、ヴ→ブ、ティ→チ、シュ/チュ等を比較用に正規化。長さに応じ最大3文字、28%以内の差を許容。短い名前は音の正規化後の一致を必要とする。
- 14呪文それぞれに明示した子ども用表記・短縮形を用意。登録候補は従来どおり追加可能。
- 最大5件の音声認識候補を比較し、完全一致を優先。異なる呪文が僅差のときは聞き直す。これは文字の照合改善であり、ブラウザの音声モデルの再学習ではない。
- 短縮例：エクスペリ、サーペン、スラグラス、ビペラ、フィニート、エバーテ。

## 検証と限界

121件の自動テスト。14呪文と全短縮形、合成した幼児発音例、日常語の棄却、代替候補の競合、設定移行、全14演出の通常/軽量更新とキャンセルを含む。

合成例は娘さんの実音声ではない。iPhone実機の音声認識率・テレビの画質・フレームレートは未測定。WebGLが使えない検証環境なので、最終映像の目視確認は未実施。判定幅を広げることで誤発動が増える可能性は残る。聞き取りで別の漢字や単語になる場合は、実際の認識履歴を呪文に追加登録して調整する。
