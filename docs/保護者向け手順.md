# 保護者向け 開始手順とテレビ接続の確認事項

## 1. 最初の1回だけやること

1. iPhone の Safari で公開URLを開きます。**Chrome や LINE 内ブラウザではなく Safari** で開いてください。
2. 右上の「⚙ ほごしゃ」を押してパネルを開きます。
3. 「はじめる（きく）」を押します。**マイクの許可を求められたら「許可」**を選びます。
   - ここで許可しないと音声は使えません。あとから iPhone の「設定 → Safari → マイク」で変えられます。
4. 「じゅもんの ひかりの いろ」を確認します。
   **初期色は説明書に書かれた色がすでに入っています**（各行に「説明書の色: 黄色」のように表示されます）。
   ただし説明書にあるのは色の名前なので、具体的な色味まで合っているかは分かりません。
   杖を光らせながらテレビを見比べて、
   - ずれていたら色を変えて各行の「保存」を押す
   - 合っていたら「実物の杖で確認した色」にチェックを入れる

   チェックは自動では付きません。保護者が見て確認したときだけ入れてください。

## 2. 毎回の遊びかた

1. URLを開く → 「⚙ ほごしゃ」→「はじめる（きく）」
2. 「とじる」でパネルをしまう（テレビにパネルが映らないようにするため）
3. 子どもが呪文を唱える
4. 認識されると「つえを ふって！」と出ます。**この約1秒のあいだに杖を振らせてください。**
5. そのあと、設定した色で光り、演出が起きます

### 入力モードの選びかた

| モード | いつ使うか |
|---|---|
| **ボタンのときだけ聞く**（初期設定） | 既定。押してから5秒だけ聞きます。iOSでの自動再開が未検証のため、こちらを既定にしています |
| **常時待ち受け** | 押しっぱなしにせず遊びたいとき。ただし iOS Safari では認識が1発話ごとに終わる可能性があり、自動の再開ができない場合は案内を出します |

### うまく動かないとき

| 症状 | 対処 |
|---|---|
| 認識されない | 「認識の厳しさ」を「ふつう」にする。診断の「認識テキスト」を見て、呪文の候補に追加する（下の4章） |
| 変な言葉に化ける | 「認識言語」を `en-US` と `ja-JP` で切り替えて比べる |
| 勝手に発動する | 「直前の発動は誤発動だった」を押して記録する。「発動待ち時間」を長くする。音量を下げる |
| 止まってしまう | 「はじめる（きく）」をもう一度押す |
| 音声がまったく使えない | 手動ボタン（14呪文すべて）で同じ演出が出せます |

## 3. テレビ接続時に確認すること

HDMIアダプタで iPhone をテレビにつないだとき、次を順に見てください。

1. **映像が出るか。** 画面は16:9に収まるよう作ってあります。横画面にすると大きく映ります。
2. **音がテレビから出るか。** 出ない場合は iPhone 側のスピーカーから出ています。どちらでも遊べます。
3. **マイクが使えるか（いちばん重要）。** アダプタをつないだまま「はじめる（きく）」を押し、呪文が認識されるか確かめてください。
   アダプタによってはマイク入力が止まることがあります。止まる場合は、
   - アダプタを変える、または
   - AirPlay でのミラーリングに切り替える、または
   - 手動ボタンで遊ぶ
   のいずれかになります。**この点は実機でしか分かりません。**
4. **テレビの音で誤発動しないか。** 呪文の効果音が鳴っている間はマイクを止めるようにしてありますが、
   それでも誤発動したら「直前の発動は誤発動だった」で記録してください。音量を下げるのも有効です。
5. **画面がスリープしないか。** しばらく触らないと暗くなる場合は、iPhone の「設定 → 画面表示と明るさ → 自動ロック」を長くしてください。
6. **発熱とコマ落ち。** 保護者パネルの「描画の負荷（実測）」に、いまのフレームレートが出ます。
   24fps を下回る状態が続くと注意が出ます。そのときは「軽量描画にする」を入れてください（自動では切り替えません）。

## 4. 認識されない呪文を覚えさせる

実機の音声認識が何を返すかは事前に分かりません。内蔵の許可リストに無い表記が返っている場合は、
**保護者が明示的に候補へ追加**できます。アプリが勝手に一番近い呪文へ寄せることはありません。

1. 呪文を唱える（認識はされるが一致しない）
2. パネルの「イベントログ」で `[utterance] transcript=...` の行を探す
3. その文字列を「認識テキストを呪文の候補に追加する」の欄に入れ、呪文を選んで「候補に追加」
4. もう一度唱えて、一致するようになったか確かめる

追加した候補はこのブラウザに保存されます。

---

## 5. 色設定を別の端末へ移す

色設定はこのブラウザの中にだけ保存されます。ブラウザのデータを消したり、端末を変えると引き継がれません。

- **書き出す**：「色設定を書き出す」を押すと、下の欄に内容が出て、クリップボードにもコピーされます。
  「実物の杖で確認した色」の印も一緒に書き出されます。
- **読み込む**：別の端末で同じ欄に貼り付けて「色設定を読み込む」を押します。
  呪文IDと色の形式を検査し、おかしな項目は適用しません。

「世界を初期化する」「Finite Incantatem」「入力モードの変更」では、色設定は消えません。

---

## 6. 遊びの安全について

画面の中の魔法は、人を押したり倒したりする表現を含みますが（Stupefy、Everte Statum）、
いずれも柔らかい着地点を描いています。実際に人を杖で押す・たたくことを促す操作はありません。
杖は振るだけで、現実では人や物に当てないよう声をかけてください。
