# 効果に対応する音響

全14呪文の着弾音を音階中心から材質音・動作音を重ねた独自合成へ変更。実物・映画の録音ではない。外部音声配信、追加料金なし。

|呪文|音の構成|
|---|---|
|Accio|吸い寄せる風、木箱の着地、金具、短い反響|
|Stupefy|鋭い衝撃、低音、衣擦れ、倒れ込む着地|
|Reducto|破裂、岩の低い振動、左右に散る細かな破片|
|Protego|空気の膨張、金属的な共鳴、低い持続音|
|Rennervate|鼓動を思わせる低音、吸気、衣擦れ、足音|
|Episkey|柔らかな空気、細かな粒、澄んだ余韻|
|Expelliarmus|弾かれる衝撃、風切り、木の杖の落下と跳ね|
|Rictusempra|くすぐりの風、笑いを思わせる息の反復、衣擦れ（人の録音ではない）|
|Serpensortia|出現時の空気、ヘビのシュー音、這う擦過音|
|Slugulas Eructo|喉の低音、水分を含む落下音、木桶の響き|
|Impedimenta|重い共鳴、徐々に間隔が開いて音が低くなる減速|
|Vipera Evanesca|シュー音、吸い込む風、小さな破裂と消える余韻|
|Finite Incantatem|解除の共鳴、吸い込む風、複数の解除音、静まる余韻|
|Everte Statum|重い衝撃、飛ぶ風、衣擦れ、着地|

発射音は映像開始、着弾音は状態変化と同じコールバック。着地は現行アニメーションの時間に合わせる（箱1.5秒、杖1.1秒、桶0.95秒）。短い反響も停止可能な音源として管理。リセット時は予約済み音源も停止。

出力にコンプレッサーを追加。StereoPanner対応環境では風と破片を左右に移動。非対応環境ではモノラル。

検証：133件の自動テスト。Chrome OfflineAudioContextで14音を音量100%・48kHz・ステレオで生成し、無音/非有限値/クリッピング/申告時間を超えた音残りを確認。iPhone→HDMI→BRAVIAでの試聴、体感音質と同期遅延は未確認。
