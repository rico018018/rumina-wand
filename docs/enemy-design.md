# 敵の衣装バリエーション

保護者メニュー「せってい → 敵のすがた」で4種類を選択。選択は既存の設定保存領域に保持する。壊れたIDは銀の仮面に戻す。

- 銀の仮面：標準の彫金面と重なるローブ。
- 細身の仮面：細い輪郭、絞った顎、深いフード、細かな縦ひだ。
- 重厚な仮面：幅広い顔、狭い目穴、幅広い肩とケープ。
- 古びた仮面：くすんだ金属、暖色の暗い布、長い肩布。

衣装変更は世界の状態をリセットしない。発動待ちを取り消し、既存のモデルのGPU資源を解放して置き換える。登場する敵は一度に一人。全種類、反撃なし、14呪文の対象として共通の関節構造を使用する。

実写映画の衣装を意識した3D造形・布の織り目・金属傷・粗さの変化を使う。俳優の映像やスキャンした人物モデルではない。WebGL描画の実機確認は別途必要。

検証：全112テスト、4衣装の有限頂点・異なる形状・関節構造・切り替え時の世界状態保持・GPU資源解放。実Canvasによるテクスチャ生成も確認。
