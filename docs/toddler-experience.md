# 横画面・幼児向け魔法体験

## UI

横画面の発動ボタンは右下148〜150×48px。マイクとカメラは左下、状態文はその上。中央に操作ボタンを置かない。マイク・カメラの起動は引き続き明示操作。保護者パネル表示中は背面の端操作を隠す。

## 演出の共通時系列

0〜650ms：対象を画面手前・中央へ滑らかに寄せて拡大。
900ms：魔法が到達。呪文固有の着弾音と世界の状態変更を同じコールバックから発生。
900〜3700ms：対象の変化と結果を見せる。対象中心の不透明な光を減らし、周辺の衝撃波・渦・火花を残す。
3700〜4600ms：元の位置・大きさに戻る。その間は次の発動を受け付けない。

実際の対象を一時的に移動・拡大し、各フレームで描画用変形を復元する。ゲーム内座標の保存値は書き換えない。

## 何度でも効果を見られるようにする

発動前に不足している対象条件だけ準備する。復活は敵を倒した状態、治癒は痛がる状態、武装解除は敵が杖を持つ状態にする。岩が全てなくなれば1個復元。消去対象のヘビがいなければ1匹生成。コレクションが上限（宝箱5個、ヘビ・ナメクジ10匹）なら最後の1個を外し、新しい対象が現れる余地を作る。Finiteに解除対象がなければヘビ・盾・壊れた岩を用意する。この動作は保護者画面に説明する。

## 音と認識

14呪文すべて独自合成音。発射・飛翔・着弾・余韻の層を使う。映像のimpactMsに合わせて着弾音を呼ぶ。実際の玩具の録音ではない。手動操作で音を有効にする既存の仕組みを保持。

初期設定は日本語・かんたん。長い認識文字列の許容差を28%→56%、最大3→6文字へ変更し、14個の短い合言葉を追加。短い語は明示した表記を中心に照合。僅差候補は棄却する。難しさが半減したことや音声認識率が倍になったことを意味しない。誤発動は増える可能性がある。認識設定バージョン3へ一度だけ移行し、その後の設定変更は保存。

## 確認の限界

横画面1363×936のUI配置をブラウザで確認。検証ブラウザのWebGLが無効なため、最終3D映像・iPhone音声・テレビ出力の目視/実機検証はできていない。自動テストは14呪文の繰り返し発動・拡大復元・短縮語・音源スケジュール・着弾タイミング・連続発動抑止を含む。
