# ハリーポッターとるみなのまほうのつえ

玩具の杖で呪文を唱えると、テレビに映した3Dの魔法世界で対応する出来事が起きる家庭内Webアプリです。
音声認識が呪文を聞き取り、**設定した待ち時間（初期値 約1秒）のあとに、その呪文に登録した色の光**が画面内に出て、
続けて演出が走ります。待ち時間のあいだに子どもが杖を振ります。

杖の動作・ボタン・成功信号・光は**いっさい検知しません**。カメラも使いません。

開発を引き継ぐ場合は [`HANDOFF.md`](HANDOFF.md) を先に読んでください。

## まだ分かっていないこと（正直に書いておきます）

このリポジトリの時点で、**実機での音声認識の挙動は一度も確認できていません**。
検証は利用者の iPhone と BRAVIA でしか決まらないため、次の点は「未確認」です。
アプリ内の「わかっていること・わかっていないこと」にも同じ内容を表示しています。

- iOS Safari で `continuous = true` が効くか。効かない場合に自動の再開がユーザー操作なしで許可されるか
- 架空の単語（Accio など）が一般語へ誤変換される度合い。`en-US` と `ja-JP` のどちらが合うか
- 3歳の声・声量での認識のしやすさ
- HDMIアダプタ接続中にマイク入力が生きるか
- テレビのスピーカーから出た効果音が誤発動を招くか
- 玩具の杖の効果音が誤発動を招くか
- 長時間の発熱・コマ落ち
- **説明書に書かれた色名と、実物のLEDの見え方が一致するか**（下の表の hex は色名からの解釈です）

**保証していないこと**

- 発音の**採点**はしていません。やっているのは認識テキストの許可リスト照合です。一致を「発音が正確」とは扱いません。
- ブラウザの音声認識は端末・ブラウザ・サービス依存です。無料・連続動作・オフライン・高精度のいずれも保証しません。
- 初期色は**購入品の説明書に記載された色**です。ただし説明書にあるのは色の**名前**なので、
  「黄色」をどの黄色にするかという具体的な値（hex）は開発側の解釈です。実物のLEDと見比べての確認はまだです。
- テレビと杖の発光色の完全な一致は保証しません。表示機器と明るさで見え方が変わります。

## 使いかた

1. 公開したURLを iPhone の Safari で開きます（マイクを使うので **https が必須**）。
2. 右上の「⚙ ほごしゃ」から保護者パネルを開き、「はじめる（きく）」を押してマイクを許可します。
3. パネルの「とじる」で遊び画面だけにします。
4. 呪文を唱えます。認識されると「つえを ふって！」と出て、約1秒後に光ります。

詳しい手順とテレビ接続の確認事項は [`docs/parent-guide.md`](docs/parent-guide.md)（保護者向け手順）にあります。
実機検証の進めかたは [`docs/device-test-checklist.md`](docs/device-test-checklist.md)（実機検証チェックリスト）にあります。

## ローカルで動かす

ビルドもインストールも不要です。静的ファイルを配るだけで動きます。

```sh
# macOS / Linux
python3 -m http.server 8777
# Windows（PowerShell / コマンドプロンプト）
py -m http.server 8777
# → http://localhost:8777/
```

`localhost` ではマイクが使えますが、**同じLANの `http://192.168.x.x` ではiPhoneのマイクは使えません**（安全なコンテキストではないため）。
iPhone で試すには https の公開URLが必要です。

## 構成

ビルド工程なし。素の ES モジュールと、同梱した three.js だけで動きます。

```
index.html          画面の骨組み
src/
  spells.js         14呪文の定義（綴り・発音ガイド・カタカナ・説明書の発光色・認識候補）
  matcher.js        認識テキスト → 呪文の照合。許可リスト方式。曖昧なら失敗にする
  world.js          魔法世界の状態機械。描画も音も音声も知らない純粋なロジック
  colors.js         呪文ごとの発光色の保存・検証・書き出し・読み込み
  speech.js         音声認識のラッパー。モード切替・再開ループ・抑制・ログ
  audio.js          効果音の合成（音声ファイルなし）
  scene.js          three.js の3D世界と発動の光
  diagnostics.js    保護者向けの診断・試験記録・認識候補の追加
  app.js            発動パイプライン（認識 → 待ち時間 → 登録色の光 → 演出）
  ui.js             画面の配線
  styles.css        見た目
vendor/             three.js r186.1（CDN非依存。vendor/README.md 参照）
test/               Node の標準テストランナー用
docs/               parent-guide.md（保護者向け手順）/ device-test-checklist.md（実機検証チェックリスト）
```

**音声発動と手動発動は同じ道を通ります。** どちらも `app.js` の `castSpell()` から `world.js` の `applySpell()` へ入り、
同じ演出・同じ状態変更・同じ色設定を使います。音声が不調でも手動で遊びを続けられます。

### 魔法の演出

どの呪文も、必ずこの順で動きます。

1. **振り** — 画面の手前を光の筋が走ります。子どもは実際にテレビの前で杖を振っているので、
   画面の魔法もその手の動きに重なるようにしています。振りの形は呪文ごとに違います
   （叩きつける／丸く囲う／横に薙ぐ／跳ね上げる／S字／くねらせる／押さえつける／手前へ引く）。
   左右の向きは毎回変わるので、同じ呪文でも振るたびに少し違って見えます。
2. **溜め** — 振り終わりの位置に光が集まります。
3. **飛翔** — そこから対象へ飛びます。
4. **着弾** — 対象で弾け、粒が散り、床に輪が広がり、衝撃波が立ち上がります。
   粒の一部は画面の手前（子どもの側）へ飛んできます。

色は保護者が設定した発光色に、色相をずらした2色めを混ぜています。1色だけだと平板に見えるためです。
淡い色（白ブルー・白紫など）は輝度に応じて光を弱め、白飛びせず色味が残るようにしています。

音も2段です。`playSwing()` が振っている間の風切り音、`playImpact()` が着弾音で、
呪文ごとに作りを変えています（重く沈む／砕ける／張られる／金属が弾かれる／ヘビの音 など）。
**実物の杖の音そのもの（ワーナーの効果音）は著作物なので複製していません。** 合成音です。
`src/audio.js` の `SPELL_SOUNDS` を書き換えれば、種類・長さ・タイミングを実物に寄せられます。

### 画面の作りについて

- **画面の中に“子どもの分身”を置いていません。** 子ども自身がテレビに向かって杖を振る側なので、
  人型のキャラクターを置くと視点が二重になります。代わりに、杖を振った先の世界を具体化しています。
- 人に作用する8呪文（Stupefy / Rennervate / Episkey / Expelliarmus / Rictusempra /
  Slugulas Eructo / Impedimenta / Everte Statum）の対象は、大広間に立つ**動くよろい**です。
  崩れる・立ち上がる・剣を飛ばされる・がたがた笑う・へこみが直る、という形で8呪文すべてが成立します。
- 大広間の**天井は夜空**です。壁と柱はそこで途切れ、浮遊する蝋燭が星空を背に浮かびます。
- 質感は手続き的なテクスチャで作っています（`src/textures.js`）。石畳・石積み・鋼・岩・木に
  それぞれムラと擦り傷を入れ、粗さのマップを分け、影を落とし、ACESのトーンマッピングで白飛びを抑えています。
- **全14呪文ぶんの対象を配置してあります。** 宝物庫（奥・Accioの供給源）、宝物置き場、壊せる岩3個と破片、
  動くよろいと落ちた剣、ヘビ、ナメクジの桶、盾、柔らかい着地点。
  よろいは左右にゆっくり見回るので、Impedimenta で遅くなったことが見て分かります。
- 遊び画面のボタンは1つだけです（右下の大きな丸）。押すと聞き取りが始まり、
  輪であと何秒聞いているかが分かります。保護者向けの設定は右上の歯車の中にまとめてあります。

### 設計上の約束

- **「認識の失敗」と「対象がない」を分ける。** 正しく唱えたのに岩がない、すでに起きている、上限に達した——これらは
  失敗演出を出さず、穏やかな合図にします（`world.js` の `status`: `applied` / `no_target` / `already` / `at_cap`）。
- **無音は失敗ではない。** 発話を受け付けて一致しなかったときだけ失敗演出を出します。権限拒否・通信エラーも別扱いです。
- **一番近い呪文へ勝手に寄せない。** `matcher.js` は許可リストの照合だけを行い、複数の呪文に同じ距離で一致したら失敗にします。
  既定の厳しさは「きびしい（完全一致のみ）」です。
- **色設定は消さない。** 世界の初期化、Finite Incantatem、入力モードの変更では色設定に触れません。保存キーも別です。
- **待ち時間のあいだに登録色を出さない。** 待ち時間中は中立色の「ためる」表示だけで、色は待ち時間のあとに出ます。
